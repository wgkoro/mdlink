# Development measurements: 2026-09-03

These early studies cover safety checks, baselines, profiles, and adopted or rejected optimizations. The [numerical evidence](data/history-2026-09-03.json) keeps each experiment separate. See the [guide](README.md) for historical source availability, recalculation, and current benchmarks.

`go_samples` records iterations, ns/op, B/op, allocs/op, and MB/s where available. Medians are calculated per field. CLI wall and CPU times are seconds; `cli.rss.samples_bytes` contains bytes. Profile `reported` fields and the initial three-run tables reproduce historical reports, not new measurements. The JSON retains source, candidate, and binary identities.

CPU and allocation profiles cover the whole test process, including setup and cleanup outside benchmark timers. Cumulative paths overlap and must not be summed. Absence from a profile's top list does not imply zero cost. Allocation totals differ from RSS.

## Environment and inputs

The machine was an Apple M4 Pro with 14 logical CPUs and 64 GiB RAM, running macOS 26.6.2 (25G83), darwin/arm64. Tools were Go 1.27.1 and its pprof, hyperfine 1.20.0, benchstat `golang.org/x/perf v0.0.0-20260825160852-19be9d8e6c70`, and Python 3.12.13. macOS `time -l` supplied RSS bytes. The main benchmarks used warm filesystems with uncontrolled desktop load; environment records retain runtime, load, and power observations.

The primary synthetic fixture used seed 20260903: 3,000 notes of 10,240 bytes and 20 links each, totaling 30,720,000 bytes and 60,000 links. It contained 300 duplicate-basename notes (150 pairs), 600 notes with Unicode or spaces in paths, 54,000 resolved links, 3,000 unresolved links, and 3,000 ambiguous links. Source and target were the first generated note, with 19 outgoing result files and 20 backlink sources expected. Expected results came from the generator, independently of the resolver. Unicode appeared in folders; the 2,850 unique basenames differ from the NFC lookup fixture below.

Private input contained 3,276 Markdown files (14,068,932 bytes), 3,324 regular files (14,338,711 bytes), four skipped symlinks, and no special files. Default `.git`, `.obsidian`, and `.trash` exclusions applied, with no additional exclusions or followed symlinks. Root/follow environment overrides were removed. Counts came from independent metadata traversal.

For later measurements with nonempty results, Markdown files directly under `Index` were sorted lexically, excluding `AGENTS.md`. Outgoing candidate 1 was 242 bytes with 3 result files/links; backlinks candidate 2 was 257 bytes with 5 referring files/links. Outgoing reported four skipped symlinks; backlinks reported 1,560 unresolved + 2 ambiguous + 4 skipped symlinks. These inputs differ from the September 14 and 21 collections.
